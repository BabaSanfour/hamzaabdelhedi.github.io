## Scope and changes

- Extended `.github/workflows/deploy.yml` to:
  - check out the public `BabaSanfour/cv-latex` `main` branch into `_cv-src`;
  - record the checked-out revision in the build log;
  - remove only the isolated checkout's exact `main.pdf` before compilation;
  - compile `main.tex` with `xu-cheng/latex-action@v3` using its verified
    `latexmk` default;
  - verify a fresh, non-empty PDF before copying it;
  - copy and byte-compare the same PDF at both the canonical and legacy site
    paths;
  - build Jekyll and fail before upload if either `_site` PDF is missing,
    differs, or if TeX/build files appear in `_site`.
- Scoped the Pages and OIDC permissions to the deploy job; the build job keeps
  `contents: read`. Existing triggers, concurrency, Node/Ruby/Bookshop steps,
  CNAME handling, and deployment actions remain in place.
- Added `scripts/sync-cv-pdf.sh` for the validated copy/compare operation and
  documented the local prebuild path and manual `workflow_dispatch` refresh in
  `README.md`.
- Changed `site/_data/links.yml` to the canonical
  `/assets/files/Hamza_Abdelhedi_CV.pdf` path. The verified public source link
  remains `https://github.com/BabaSanfour/cv-latex`.
- Updated the Hero Bookshop preview default and added a visible “View source on
  GitHub” link beside the About-page CV button. Both use the shared link data;
  new-tab links have `rel="noopener"`.
- Added `_cv-src/` and the generated canonical PDF to `.gitignore`. The
  committed legacy PDF remains present and was restored unchanged after local
  validation.
